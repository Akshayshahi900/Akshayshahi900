## 🌙 Spotlight: [Luna](https://github.com/Akshayshahi900/Luna)

A voice-first personal assistant built on **LangGraph**. One main agent handles quick tasks and hands bigger jobs to helper agents: **researcher** (web), **files**, **coder** and **assistant** (Gmail, Google Calendar and Google Tasks over MCP). Anything risky, like writing files, running commands or sending mail, waits for your approval.

- 🎙️ Local voice: Whisper to listen, Piper to speak, plus a "Hey Luna" wake word
- 📱 Remote control from Telegram, with voice notes, photos and one-tap approvals
- 🔌 Runs on OpenRouter, Groq or a local Ollama model

[Website](https://akshayshahi900.github.io/Luna/) · [Repo](https://github.com/Akshayshahi900/Luna)
